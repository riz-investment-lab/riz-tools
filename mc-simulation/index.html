Phase 1｜設立初年度（子在学中・手当は両方受給済）
項目MCなしMCあり差額
📌 Phase 1のポイント この時期は子が在学中のため、単身赴任手当は両シナリオで受給済みです。 MC設立コスト・固定費が発生するため先行投資期間となります。 翌年以降で一気に回収します。
Phase 2｜妻報酬開始・単身赴任継続認定後（年間）
項目MCなしMCあり差額
📌 Phase 2のポイント MCなしでは子卒業後に単身赴任手当が消滅し、旅費4往復が全額自己負担になります。 MCありでは妻に収入があるため単身赴任が継続認定され、 旅費2往復分が法人の出張費として処理されます。
Phase 3｜退職後（2031年〜）3シナリオ比較
項目MCあり無職（初年）無職（2年目〜）
📌 退職後のポイント 無職の場合、退職初年度は前年（会社員時代）の収入に基づいて国保が算定されるため上限付近になります。 MCありでは妻を短時間従業員（週20時間未満）にすることで妻の社会保険加入義務を回避し、 妻をRyoの被扶養者として協会けんぽに加入させることができます。
